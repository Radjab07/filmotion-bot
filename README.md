# 🤖 WhatsApp Бот для Filmotion (Creative Multimedia Lab)

Бесплатный WhatsApp-бот для автоматических ответов на вопросы клиентов, демонстрации каталога услуг компании **Filmotion** и проведения квалификационного опроса (бриф: задача, сроки, бюджет, контакты).

## 🚀 Возможности бота

- 📋 **Интерактивное Главное меню**: 8 основных пунктов (услуги, портфолио, контакты).
- 🎨 **Подробное описание 6 направлений услуг**:
  1. Сценический дизайн и медиа-оформление
  2. Интерактивные инсталляции, VR/AR, 3D-Mapping
  3. Мультимедийные презентации & Видеопродакшн
  4. 3DOOH, CGI & 3D-Графика / VFX
  5. Оформление выставочных стендов
  6. Техническое сопровождение & Сетап оборудования
- 📝 **Пошаговый опрос (Сбор брифа)**:
  - Суть задачи / Описание проекта
  - Ориентировочные сроки / Дата мероприятия
  - Бюджет проекта
  - Имя клиента и название компании
- 📩 **Авто-отправка заявки менеджеру**: После завершения опроса бот мгновенно пересылает готовую карточку лида на выбранный номер менеджера в WhatsApp.
- 🔄 **Возврат в меню и сброс**: Нажатие `0` в любой момент возвращает клиента в главное меню.

## 🛠 Подготовка к запуску

На вашем компьютере должен быть установлен **Node.js** (версия 16 или выше).
* Если Node.js еще не установлен, скачайте его с официального сайта: [nodejs.org](https://nodejs.org/).

---

## 📲 Инструкция по запуску

1. Перейдите в папку бота в командной строке / терминале:
   ```bash
   cd C:\Users\beken\.gemini\antigravity\scratch\filmotion-whatsapp-bot
   ```

2. Запустите бота командой:
   ```bash
   npm start
   ```
   *(или `node index.js`)*

3. В консоли появится **QR-код**.
4. Откройте **WhatsApp** на телефоне (на котором должен работать бот).
5. Перейдите в **Настройки ➔ Связанные устройства ➔ Привязать устройство** и сканируйте QR-код из консоли.
6. Бот подключится и напишет в консоли: `✅ WhatsApp Бот Filmotion успешно запущен и готов к работе!`.

## ⚙️ Настройка номера менеджера

Откройте файл `index.js` и в верхней части найдите строчку:

```javascript
const MANAGER_PHONE = '77051110511'; // Укажите номер без знака +
```

Замените `77051110511` на ваш номер WhatsApp, куда бот должен пересылать готовые заявки клиентов.
